# Mohanji — Japanese Kanji Flashcards

Your personal Japanese kanji flashcard app. Built with pure HTML/CSS/JS.

## Features
- Flashcard flip with 3D animation
- Swipe left/right to mark cards
- SM-2 spaced repetition scheduling
- JLPT N5-N1 preset sections
- 33,000+ word offline dictionary with auto-fill
- Test mode with score tracking
- Works offline (PWA)

## Usage
Open [the app](https://yourusername.github.io/mohanji/) in any browser.

Add to home screen for the best experience:
- **Android**: tap ⋮ → "Add to Home Screen"
- **iPhone/iPad**: tap Share → "Add to Home Screen"
